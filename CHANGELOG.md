## [0.1.0] - 2026-07-21

### Added

- Rust-native dead Python code analysis built on vendored Ruff parser crates.
- Vulture-compatible findings V101 through V107 and V201.
- Text and JSON output, confidence filtering, exclusions, decorators, and `noqa` support.
- A pinned, data-driven Vulture compatibility corpus.
- Native release archives and `ghostbuster-code` PyPI wheel automation.
